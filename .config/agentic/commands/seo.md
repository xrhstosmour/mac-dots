# SEO Analysis

Run an SEO audit using the `seo` skill instructions.

## When to use

- `/seo <url>`
- User asks for an SEO audit, health check, or "what's wrong with this page for SEO".
- User asks about a specific slice: technical SEO, schema/structured data, content quality/E-E-A-T, sitemap, image optimization, or AI-search visibility (GEO/AEO/AI Overviews).
- User pastes HTML, a sitemap, or `robots.txt` and wants it checked.
